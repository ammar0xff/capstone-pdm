# File map

This is the index of the repository. It describes what each area is for and
which files are sources, runtime state or generated outputs. Do not delete data
files just because they look stale; confirm with the owner first.

## Edge runtime (`edge/`)

| Path | Role | Runs how |
|---|---|---|
| `edge_daq.py` | Sensor drivers, SPC gate, classifier call, state/history publication | `pdm-daq.service` |
| `dashboard.py` | Presentation-only Flask server and JSON state endpoints | `pdm-dashboard.service` |
| `firebase_mirror.py` | HTTPS PUT mirror with quota guard and backlog | `pdm-cloud.service` |
| `calibrate.py` | Operator-run six-face/thermal calibration runner | Manual on Pi |
| `raw_measure.py` | Raw, uncalibrated ADXL345/MAX6675 reader with optional CSV | Manual on Pi |
| `exhibition_drill.py` | Exhibition rehearsal tool | Manual |
| `stream_live.py` | Live stream helper | Manual |
| `generate_qr.py` | QR generation helper | Manual |
| `cal.json` | Active runtime calibration consumed by `edge_daq.py` | Runtime state |
| `cloud_config.json`, `cloud_backlog.json` | Mirror configuration/offline queue | Runtime state |
| `latest_state.json`, `hot_backup.csv` | Live state and local history | Runtime state |
| `templates/index.html` | Local dashboard template | Rendered by `dashboard.py` |
| `pdm-*.service` | systemd unit sources | Copy to `/etc/systemd/system/` |
| `calibration_certificate.md`, `calibration_runs.jsonl`, `calibration_backups/` | Calibration outputs | Generated by `calibrate.py`; ignored by git |

The dashboard exposes only read-only JSON endpoints and page rendering. The old
`/api/cal` write route was removed; calibration changes go through
`edge/calibrate.py` on the Pi.

## Circuit package (`circuit/`, `book_assets/`)

- `circuit/design.py` — source of truth for parts, pins and nets.
- `circuit/build.py`, `checks.py`, `render.py` — build, verify and render.
- `circuit/fzz/` — Fritzing sketch builder and export audit.
- `circuit/out/` — generated schematics, wiring, netlist, ERC report, Fritzing files.
- `circuit/bom_target.csv`, `BOM_reconciliation.md` — build list and budget decisions.
- `book_assets/make_charts.py` + `book_assets/*.png` — chart generation for the book.

Edit `design.py` and rebuild; never hand-edit `circuit/out/`.
