0A — The Problem

Egyptian factories lose production not because machines are weak, but because failures are surprise. A single motor bearing seizure stops a whole line for hours while a technician travels, diagnoses, orders a spare, and restarts.

  • Reactive maintenance (fix after break): cheapest upfront, most expensive downtime — $50B/yr globally, 5–20% capacity lost (Deloitte 2017, Mourtzis 2020).
  • Preventive maintenance (fix on schedule): replaces healthy parts, still misses early faults, wastes spares and labour.
  • Missing sensing: small factories have no vibration / temperature / acoustic logging, no wireless to cloud, no AI — so no early warning, no data for decisions.
  • School constraint: must prove sensing + wireless to cloud + AI + hardware + ≥80% accuracy + calibration + portable testable prototype, no Arduino.
Problem statement: How can AI + IoT on a low-cost edge device detect incipient motor faults (vibration / heat / sound) and warn in ≤5s, with evidence, without paid cloud?

2 — Scientific Base & Physics

2.1 Vibration — Newton's 2nd law → bearing fingerprints

A MEMS accelerometer (ADXL345) is a micro silicon mass on springs. Acceleration deflects capacitive fingers: F = m·a, C = εA/d. Chip reads ΔC → 13-bit digital g. Range ±2g/4g/8g/16g; we use ±4g for motors.

a(t) = A·sin(2πft + φ)    |    RMS = √(1/N ∑xi²)    |    Kurtosis = E[(x−μ)⁴]/σ⁴Healthy ≈ 3.0 (Gaussian). Faulty impacts → kurtosis 6–15. Crest = peak/RMS spikes first.
DFT: X[k] = ∑n=0N−1 x[n]·e−j2πkn/N   •   Nyquist: fs > 2·fmaxWe sample 50–200 Hz → see faults to 25–100 Hz. Bearing tones live there.

Bearing fault frequencies (n balls, d ball Ø, D pitch Ø, θ contact angle, fr shaft Hz):

BPFO = n/2·fr(1−d/D·cosθ)    BPFI = n/2·fr(1+d/D·cosθ)    BSF = D/2d·fr[1−(d/D·cosθ)²]Example: 8-ball 50Hz motor → BPFO ~150Hz, BPFI ~250Hz. Our FFT (see §6 chart) shows the 95Hz class clearly separating healthy/faulty.

2.2 Temperature — Why a K-type thermocouple + MAX6675

Seebeck effect: two dissimilar metals joined at the probe tip produce an EMF proportional to the difference between that junction and the “cold” junction where the wires meet the screw terminals. S ≈ 41 µV/°C near room temperature, so the whole 0–100 °C signal is only 4.1 mV. A K-type covers −200…+1250 °C, has a tiny junction (τ ≈ 4 s) and needs no excitation current, so it cannot self-heat. The price of that range and speed is accuracy: ±2 °C for this chain instead of the ±0.4 °C a PT100 + MAX31865 would give (250+200 vs 220+380 EGP — the swap saves 150 EGP, not the reason).

V = S·(Thot − Tcold) , S ≈ 41 µV/°C0 °C→0.000 mV · 100 °C→4.096 mV · 300 °C→12.209 mV (NIST ITS-90 table, see §7 curve). MAX6675 measures its own die as Tcold, amplifies, linearises and returns 12 bits over SPI: 0.25 °C per step, 220 ms per conversion, plus an open-thermocouple flag.

Cold junction is the accuracy limit. The chip assumes its terminal block is at the same temperature as its die. Mount the module beside the Pi (box air +12 °C) and every reading is wrong by exactly that offset. Rule: module ≥15 cm from the Pi and its regulator, isothermal terminal block, 5-minute warm-up before calibration. The probe class then decides M4: class 1 (±1.5 °C) gives a 1.68 °C RSS; a class-2 probe is ±2.5 °C on its own and forces M4 to ±2.5 °C. Ordering rule: specify class 1. Thin thermal paste + M6 screw = conduction path, τ≈4 s.

2.3 Acoustics — Sound pressure → MEMS → MFCC

SPL(dB) = 20·log10(p / p0), p0=20μPa   •   INMP441: capacitive membrane → ΣΔ ADC → I2S 16kHz/24-bitBearing squeal 2–6kHz, rub 500Hz–2kHz. Features: ZCR, RMS, MFCC (mel filterbank + DCT) — same as speech recognition, robust to factory noise.

2.4 Electrical & Comms physics

  • Decoupling: 100nF ceramic Z=1/(jωC) shorts HF noise at sensor VCC; 10μF electrolytic holds bulk during SPI bursts. Without them ADXL shows ±0.1g hash.
  • Pull-ups: 10kΩ on I2C SDA/SCL + SPI CS idle-high; value = trade-off speed vs power (τ=RC).
  • Shielding: braided shield tied at Pi GND single-point drains EMI. A thermocouple needs it more than any other sensor: the signal is a few millivolts, so the pair is twisted and the shield is grounded at the Pi end only.
  • I2C (ADXL345): 2-wire, 400kHz, address 0x53 (SDO→GND) / 0x1D (SDO→VDD). SPI (MAX6675): 3-wire read-only SCK/SO/CS, mode 0 at 1 MHz — no MOSI, so CS low → 16 clocks → 12-bit result + open-TC flag. I2S (INMP441): BCLK+WS+SD continuous audio clock, DMA-fed.
  • Nylon isolation: breaks ground loop magnet→chassis→Pi (would inject 50Hz hum). Nylon R>10MΩ.

2.5 Data-science base (Cinar Ch.3)

UCL/LCL = μ ± 3σ (X-bar),   Warning = μ ± 2σ   •   Acc = (TP+TN)/N, F1 = 2PR/(P+R)CLT: windowed RMS ≈ Gaussian → Shewhart valid. Coarse SPC gates expensive DL → 10× fewer inferences, fewer false alarms. DL triggered only out-of-control (Fig.11).

4.2 Schematics

Mechanical stack (prevents 50Hz hum + heat short): motor → magnet (steel) → M3 screw → nylon washer → ADXL PCB → nylon standoff → nut. K-type M6 screwed to a flat spot with thermal paste, finger-tight — keep the MAX6675 module away from the Pi's heat. Mic on standoff, port facing bearing, foam windscreen if dusty.
Common kills: 5V into sensor (dead), SDA/SCL swapped (no ACK), SPI mode 0 vs 1 (MAX6675 returns 0), T+ / T− reversed (reads colder as the motor heats), module beside the Pi (cold junction 12 °C off), I2S WS wrong pin (silence), shield tied both ends (loop). Check each with i2cdetect -y 1 → 0x53 must appear.

5.1 Edge DAQ + SPC + local MQTT + SD + Firebase mirror (0 EGP)

# edge_daq.py — offline-first: local MQTT + Flask primary, Firebase mirror 1/15s
import time, json, csv, collections, os
import board, busio, digitalio
import adafruit_adxl34x, adafruit_max6675
import numpy as np, paho.mqtt.client as mqtt, requests
# --- config ---
CAL = json.load(open('cal.json'))
FB_URL = os.getenv('FB_URL','https://<proj>.firebaseio.com/motor1.json')
FB_KEY = os.getenv('FB_KEY','DEMO_KEY')
i2c = busio.I2C(board.SCL, board.SDA)
acc = adafruit_adxl34x.ADXL345(i2c); acc.range = adafruit_adxl34x.Range.RANGE_4_G
acc.data_rate = adafruit_adxl34x.DataRate.RATE_800_HZ  # chip anti-alias = fs/2
spi = busio.SPI(board.SCK, board.MOSI, board.MISO)
cs = digitalio.DigitalInOut(board.D8)
tc = adafruit_max6675.MAX6675(spi, cs)   # 12-bit, 220 ms, cold junction inside
mq = mqtt.Client(); try: mq.connect('localhost',1883,60); mq.loop_start()  except: pass  # local Mosquitto, works offline
buf = collections.deque(maxlen=1000)
ts  = collections.deque(maxlen=8192)      # sample timestamps
raw = collections.deque(maxlen=8192)      # (x,y,z) in g
mu,sg = 0.35,0.04; last_fb = 0; writes = 0
logf = open('hot_backup.csv','a',newline=''); wr=csv.writer(logf)
def uniform(ts, raw, n=4096):
    # resample on real timestamps: OS jitter must not invent or hide a tone
    t = np.asarray(ts,float); t -= t[0]
    a = np.asarray(raw,float) - np.mean(raw,axis=0)  # g, gravity removed
    u = np.linspace(0,t[-1],n)
    return np.sqrt(sum(np.interp(u,t,a[:,i])**2 for i in range(3)))
def features(w):
    rms = float(np.sqrt((w**2).mean()))
    return rms, float(((w-w.mean())**4).mean()/(w.var()**2+1e-12))  # true kurtosis
while True:
    t0 = time.perf_counter()
    x,y,z = acc.acceleration
    ts.append(t0); raw.append((x,y,z))
    time.sleep(max(0,1/800-(time.perf_counter()-t0)))   # 800 Hz target
    if len(raw) < 4096: continue          # 4096/800 = 5.12 s window
    w = uniform(ts,raw); rms,kurt = features(w)
    g = float(np.sqrt(x*x+y*y+z*z))
    t = float(tc.temperature)*CAL['t_a']+CAL['t_b']  # cal cancels probe offset
    fs = round(len(ts)/(ts[-1]-ts[0]),1)            # prove the achieved rate
    flat = round(float(np.linalg.norm(np.mean(raw,axis=0))),3)  # ~1.0 g = still bolted flat
    state='Healthy'
    if rms>mu+3*sg or kurt>6 or t>75: state='Fault'
    elif rms>mu+2*sg or t>60: state='Warning'
    pkt={'g':round(g,3),'rms':round(rms,3),'kurt':round(kurt,2),
         'flat':flat,'fs':fs,'temp':round(t,2),'state':state,
         'ts':time.time(),'seq':writes}
    ts.clear(); raw.clear()                            # next window starts fresh
    try: mq.publish('factory/motor1',json.dumps(pkt),qos=1)  except: buf.append(pkt)
    wr.writerow(pkt.values()); logf.flush()
    # Firebase mirror throttled: 1/15s normal, 1/60s if >15k writes/day
    interval = 15 if writes < 15000 else 60
    if time.time()-last_fb > interval:
        try: requests.put(FB_URL, params={'auth':FB_KEY}, json=pkt, timeout=5); last_fb=time.time()
        except: buf.append(pkt)  # offline → backfill later
    writes+=1
