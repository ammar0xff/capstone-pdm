Stage 1: Statistical Process Control (SPC) AWAITING DATA

Continuous statistical check on vibration RMS and temperature rise. On a nominal window the classifier wrapper returns without running the Random Forest, so no fault class is produced while the machine is quiet.

Stage 2: 300-Tree Random Forest Classifier AWAITING DATA

Runs on an anomaly breach and classifies the current state into Healthy, Mechanical Imbalance, Bearing Defect or Thermal Runaway. The result is a four-class diagnosis plus an operator action, not a remaining-life prediction.

Mathematical Formulations & In-Place Physics Verification

VALUES FROM CURRENT PACKET
1. Dynamic RMS Energy ISO 20816
RMS = √[ Σ(adyn[i])2 / N ]
Awaiting telemetry
Quantifies continuous kinetic mechanical stress. Rises proportionally with rotating unbalance and misalignment forces (F = m · r · ω2).
2. Vibration Kurtosis 4th Standardized Moment
κ = μ4 / σ4 = [ Σ(a - μ)4 / N ] / σ4
Awaiting telemetry
Measures heavy-tailed shocks. Bearing-fault theory links spall impacts to high kurtosis before RMS rises; no real-motor lead time has been measured on this rig.
3. Crest Factor (CF) Shock-to-RMS Ratio
CF = Peakdyn / RMSdyn
Awaiting telemetry
Ratio of localized impact amplitude to background mechanical energy. Distinguishes impulsive spall clicks from steady distributed vibration.
4. Shewhart SPC Z-Score Stage 1 Gating
Z = (RMSdyn - μ0) / σ0
Awaiting telemetry
Shewhart check on dynamic RMS. A nominal window skips the Random Forest; CPU savings from that skip have not been measured.
5. Thermal Derivative Runaway Rate (dT/dt)
ΔT/Δt = (Tnow - Tpast) / (Δt / 60) [°C/min]
Awaiting telemetry
Detects a rapid temperature rise. It is one input to the thermal-fault class; no warning lead time has been measured on a real motor.
6. Acoustic Pressure & ZCR High-Frequency Friction
SPL = 120 + 20·log10(RMS) | ZCR = Σ|sgn(Δs)| / 2M
Awaiting telemetry
Airborne acoustic emissions capture metal-on-metal rubbing and friction squeal in audible/ultrasonic spectra, driving high zero-crossing rates.
